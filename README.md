# 🛡️ AppScreenControl — Система родительского контроля

Полнофункциональное решение для мониторинга экранного времени и просматриваемого контента на Android-устройствах (для Брата и Сестренки).

---

## 📁 Структура проекта

* `server/` — **Бэкенд-сервер (Node.js/Express) + Веб-дашборд (UI)**
  * `server.js` — REST API для приема статистики, логов экрана и pings с устройств.
  * `data.json` — База данных для сохранения истории.
  * `public/` — Премиальный веб-интерфейс (графики, лента активности, текущий статус устройств).
* `android/` — **Нативное Android-приложение (Kotlin)**
  * `AccessibilityService` — перехватывает заголовки видео в YouTube, поисковые запросы в Chrome/TikTok.
  * `UsageStatsManager` — точный ежедневный учет времени в каждом приложении.
  * `WorkManager` — фоновая синхронизация с сервером каждые 15 минут.
  * `MainActivity` — удобный экран выбора профиля («Брат» / «Сестренка») и выдачи разрешений.

## 🚀 Быстрый запуск сервера и Дашборда

1. Откройте терминал в папке `server`:
   ```bash
   cd server
   npm start
   ```
2. Откройте браузер по адресу:
   * На вашем компьютере: **`http://localhost:3000`**
   * С других устройств в той же Wi-Fi сети: **`http://<IP_ВАШЕГО_КОМПЬЮТЕРА>:3000`** (например, `http://192.168.1.50:3000`)

На дашборде вы сразу увидите активный интерактивный интерфейс с предзагруженными демо-данными (можно переключаться между вкладками «Брат» и «Сестренка», тестировать симулятор активности).

## 📱 Установка трекера на телефоны детей (Android)

### Шаг 1: Сборка APK
1. Откройте проект в папке `android/` в **Android Studio**.
2. Нажмите **Build -> Build APK(s)** или выполните команду в консоли:
   ```bash
   cd android
   ./gradlew assembleDebug
   ```
3. Готовый APK файл будет в: `android/app/build/outputs/apk/debug/app-debug.apk`.

### Шаг 2: Настройка на телефоне детей
1. Передайте и установите `app-debug.apk` на телефон Брата и Сестренки.
2. При первом запуске:
   - Укажите **IP-адрес сервера** (например, `http://192.168.1.50:3000`).
   - Выберите чей это телефон (**👦 Брат** или **👧 Сестренка**).
   - Нажмите **«Включить»** напротив **Доступ к статистике** и выберите *AppScreenControl*.
   - Нажмите **«Включить»** напротив **Службы спец. возможностей** (Accessibility Service) и включите *AppScreenControl*.
3. Нажмите **«🚀 Сохранить и запустить»**.

После этого приложение начнет автоматически передавать время использования и открываемый контент на ваш сервер и вы увидите реальные данные в дашборде!
